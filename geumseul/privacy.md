# 금슬 개인정보 처리방침

시행일: [출시일에 확정]

이 방침은 금슬 iOS 앱(이하 "앱")에만 적용됩니다. Team Cumulus(이하 "팀")가 운영하는 웹사이트와 다른 앱에는 [Team Cumulus 개인정보 처리방침](/privacy/)이 적용되며, 앱에 관해서는 이 방침이 우선합니다.

금슬은 커플·부부가 서로의 마음을 더 잘 알도록 돕는 관계 웰니스 앱으로, 두 사람 모두 만 19세 이상만 이용할 수 있습니다. 팀은 「개인정보 보호법」 제30조에 따라 이용자의 개인정보를 보호하고 관련 고충을 신속하게 처리하기 위하여 다음과 같이 개인정보 처리방침을 수립·공개합니다.

## 1. 수집하는 정보와 수집 방법

앱은 서비스 제공에 필요한 최소한의 정보만 수집합니다. 이메일 주소, 전화번호, 실명, 연락처, 위치, 사진은 수집하지 않습니다.

### 서비스 이용 과정에서 수집하는 항목

| 구분 | 항목 | 수집 방법 | 비고 |
|---|---|---|---|
| 계정 | 익명 계정 식별자(무작위 UUID) | 앱 첫 실행 시 자동 생성(익명 인증) | 이메일·전화번호·비밀번호가 없습니다. 기기를 바꾸면 같은 계정을 복구할 수 없습니다. |
| 프로필 | 닉네임(1~10자) | 이용자 입력 | 연결된 파트너에게 표시됩니다. |
| 성인 확인 | 만 19세 이상 확인 시각 | 가입 시 이용자의 자기 선언 | 생년월일·신분증 정보는 수집하지 않습니다. 선택 기능을 켤 때 다시 확인한 시각도 함께 보관합니다. |

### 서버에 저장하지 않고 기기에만 두는 정보

다음 정보는 이용자의 기기(보안 저장소·키체인)에만 있으며 팀의 서버·결제 수탁자·파트너에게 전송하지 않습니다.

- 커플 열쇠(couple_key): 초대 링크의 `#` 뒤(URL fragment)로만 전달되어 서버에 전송되지 않습니다. 기기를 바꾸면 iCloud 키체인 동기화 또는 파트너 기기의 QR로 복구합니다.
- "우리 관계 단계" 선택과 시작하기 기록, 온보딩 작성 중 초안, 앱 잠금 설정, 첫 결제 화면을 봤는지 여부

## 2. 민감정보의 처리

1. 앱의 친밀감 카드 답, 경계, 친밀감 대화 카드 답, 주간 체크인 값은 **성생활 등에 관한 정보**로서 「개인정보 보호법」 제23조의 민감정보에 해당합니다.
2. 팀은 민감정보를 처리하기 전에 다른 개인정보 처리에 대한 동의와 **별도로** 이용자의 동의를 받습니다(앱 안 '민감정보 동의' 화면). 두 사람이 모두 동의해야 친밀감 질문이 나옵니다.
3. 동의하지 않아도 관계 대화 카드, 커플 연결, 설정 등 기본 기능은 그대로 이용할 수 있습니다.
4. 민감정보는 1항과 같이 **기기에서 암호화된 토큰·암호문**으로만 서버에 저장되어 팀이 내용을 알 수 없습니다. 주간 체크인 원값은 비교 직후 삭제합니다.
5. 이용자는 설정에서 언제든 동의를 거둘 수 있습니다. 동의를 거두면 이용자의 카드 답(경계 포함), 상호 공개 토큰(우리의 매치·이야기해볼 것), 친밀감 대화 답, 입력 중인 체크인 값을 즉시 삭제하며, 우리의 매치는 파트너의 목록에서도 사라집니다. 오늘 나눈 친밀감 대화 답은 파트너의 것도 삭제됩니다.

## 3. 처리 목적

| 목적 | 사용하는 항목 |
|---|---|
| 계정 생성·식별, 앱 재실행 시 이용자 구분 | 익명 계정 식별자 |
| 커플 연결과 파트너 표시 | 닉네임, 커플 연결 관계, 초대 코드 |
| 상호 공개(둘 다 '예'인 항목만 공개), 이야기해볼 것 목록 | 카드 답 암호화 토큰 |
| 대화 카드(둘 다 답하면 서로의 답 공개) | 대화 카드 암호문, 답한 날짜·질문 식별자 |
| 주간 체크인에 따른 대화 카드 추천 | '차이 큼' 여부 |
| 성인 전용 서비스 운영과 선택 기능의 열림 조건 판정 | 성인 확인 시각, 민감정보 동의 여부, 선택 기능 스위치 상태, 구독 상태 |
| 커플 단위 구독 제공(한 명 결제 시 파트너도 프리미엄), 구매 복원 | 구독 상태·상품·만료 예정일 |
| 법령상 의무 이행(전자상거래 기록 보존 등), 분쟁 대응 | 구독 이벤트 기록 |

팀은 개인정보를 마케팅, 광고, 프로파일링, 제3자 판매에 이용하지 않습니다.

## 4. 보유 및 이용 기간

1. 팀은 수집·이용 목적이 달성되면 지체 없이 파기합니다. 원칙적으로 **계정 삭제 시 서버의 모든 기록을 즉시 삭제**합니다.
2. **연결 해제** 시 우리의 매치·이야기해볼 것·대화 기록을 두 사람 모두에게서 즉시 삭제합니다.
3. **민감정보 동의 철회** 시 2항 5호의 항목을 즉시 삭제합니다.
4. 주간 체크인 원값은 두 값 비교 직후, 파트너가 입력하지 않으면 그 주가 끝날 때 삭제합니다.
5. 다음 정보는 관련 법령에 따라 정한 기간 동안 보존합니다.

| 보존 항목 | 근거 법령 | 기간 |
|---|---|---|
| 계약 또는 청약철회 등에 관한 기록 | 전자상거래 등에서의 소비자보호에 관한 법률 | 5년 |
| 대금결제 및 재화 등의 공급에 관한 기록 | 전자상거래 등에서의 소비자보호에 관한 법률 | 5년 |
| 소비자의 불만 또는 분쟁처리에 관한 기록 | 전자상거래 등에서의 소비자보호에 관한 법률 | 3년 |
| 서비스 접속 기록 | 통신비밀보호법 | 3개월 |

## 8. 자동 수집 장치의 설치·운영 및 거부

1. 앱은 쿠키를 사용하지 않습니다(웹사이트가 아닌 모바일 앱).
2. 앱에는 분석(애널리틱스)·광고·추적 SDK가 없습니다. 이용자의 행동을 다른 회사의 앱·웹사이트와 연결해 추적하지 않으며, Apple 앱 추적 투명성(ATT) 권한을 요청하지 않습니다.
3. 결제 처리를 위해 포함된 RevenueCat SDK가 수집하는 항목은 1항과 같으며, 이는 광고·추적 목적이 아닙니다.

## 9. 안전성 확보 조치

1. **종단간 암호화(E2E)**: 카드 답은 커플 열쇠로 만든 HMAC 토큰, 대화 카드 답은 커플 열쇠로 암호화한 암호문으로만 서버에 저장되고, 커플 열쇠는 서버에 없으므로 팀은 내용을 복호화할 수 없습니다. 일치 비교는 서버 함수가 토큰만으로 수행합니다.
2. **최소 수집**: 이메일·전화번호·실명 없는 익명 계정. 주간 체크인 원값은 비교 후 즉시 삭제.
3. **접근 통제**: 행 수준 보안(RLS)으로 본인의 행만 읽을 수 있고, 민감한 테이블은 별도 스키마에 두어 서버 함수만 접근합니다. 상대의 '아니오'·'절대 안 함'·선택 기능 스위치 상태는 노출되지 않습니다.
4. **전송 보호**: 모든 통신은 TLS로 암호화합니다.
5. **앱 보호**: 생체 인증·기기 암호 기반 앱 잠금, 민감한 화면의 화면 캡처 차단, 백그라운드 전환 시 화면 가림.
6. **운영 보호**: 결제 알림(웹훅)은 비밀값으로 검증하며, 로그·오류 보고에 답·항목명·체크인 원값을 남기지 않습니다.
7. **내부 관리**: 개인정보 취급자를 최소한으로 지정하고 접근 권한을 관리합니다.
